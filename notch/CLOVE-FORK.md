# Clove Notch

A personal fork of [Coucou](https://github.com/Louis-CFM/coucou) by Louis Raillé (code under the MIT License, see
`LICENSE`), rebranded as **CLOVE** and connected to the CLOVE assistant. Coucou's name, its Mochi character, icon
and sounds belong to its author (`LICENSE-ASSETS.md`), so this fork replaces all of them with its own:

| | Upstream | This fork |
|---|---|---|
| Name, window titles, every string in every language | Coucou / Mochi | CLOVE |
| App id, binary, hook, socket, config | `fr.louisraille.coucou`, `coucou`, `coucou-hook`, `coucou.sock`, `~/.config/coucou` | `dev.clove.notch`, `clove-notch`, `clove-notch-hook`, `clove-notch.sock`, `~/.config/clove-notch` |
| Character | Mochi (face, eyes, hands, outfits, greeting wave) | the CLOVE mark: four sepals and a bud in a state ring (`drawCloveMark` in `windows/src/mochi/engine.ts`) |
| Icon | Coucou icon | `windows/branding/clove-icon.svg` |
| Sounds | the Mac app's WAVs | `windows/branding/sounds`, generated by `windows/branding/make_sounds.py` |
| Wordmark | — | Eurostile Extended Bold if installed, else Michroma (SIL OFL, `windows/public/fonts`) |
| Wardrobe | outfits for Mochi | removed from the menu (the mark has none) |
| Updates | from upstream's GitHub releases | off: upstream releases are the original app |
| Accent of CLOVE's pill and chat | — | `#FB923C`, the CLOVE orange (the hub's accent); `clove/docs/DESIGN.md` lists the shared tokens |

Unchanged on purpose: links to the upstream repository (credit), and the phone-link protocol ids (`coucou://pair`,
`coucou-relay/v1`, `coucou.v1`, `_coucou._tcp`), so the phone app still pairs.

**Clove Notch** was called the CLOVE island until 0.2.0. Everything a person sees or types says Clove Notch: the app,
its settings, the commands `clove-notch` and `clove-notch-hook`, and its folders `~/.config/clove-notch` and
`~/.local/share/clove-notch`. On first start it moves the old `clove-island` folders and keys there and leaves a
link at each old path, so hooks written before the rename keep working. Names inside the code (`src/island/`,
`island.rs`, the window label `island`) are upstream's and stay, so upstream changes still merge.

## Connected to CLOVE

- **Chat**: the default chat provider is CLOVE (`windows/src-tauri/src/clove_chat.rs`). Questions go to the running
  CLOVE over its owner-only control socket (`~/.local/state/clove/ctl.sock`) and CLOVE answers with its own brain,
  memory and tools.
- **CLOVE's own pill**: CLOVE reports its requests, tool steps, replies and finished jobs to Clove Notch
  (`clove/notch.py`), and a plan that needs approval comes up as an Allow / Deny card that approves or rejects it.

- **The Assistant pages** (first in the window's sidebar, and its default page): the CLOVE assistant's own window
  (`clove/ui`) in a frame (`windows/src/hub/clove.ts`). Its address comes from `$XDG_RUNTIME_DIR/clove.url`, written
  by CLOVE at start and checked before use (`src-tauri/src/clove_window.rs`); the window's CSP allows frames from
  `http://127.0.0.1:*` only. When CLOVE isn't running the page says so and can start its systemd user service.
  `clove-notch --page assistant` opens the window there (CLOVE does this when it is asked for its window).

## Build and install

```bash
npm install && npx tauri build --no-bundle
install -m755 target/release/clove-notch ~/.local/bin/clove-notch
install -m755 target/release/clove-notch-hook ~/.local/bin/clove-notch-hook
```
