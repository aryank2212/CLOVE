# Clove Notch

A personal fork of [Coucou](https://github.com/Louis-CFM/coucou) by Louis Raillé (code under the MIT License, see
`LICENSE`), rebranded as **CLOVE** and connected to the CLOVE assistant. Coucou's name, its Mochi character, icon
and sounds belong to its author (`LICENSE-ASSETS.md`), so this fork replaces all of them with its own:

| | Upstream | This fork |
|---|---|---|
| Name, window titles, every string in every language | Coucou / Mochi | CLOVE |
| App id, binary, hook, socket, config | `fr.louisraille.coucou`, `coucou`, `coucou-hook`, `coucou.sock`, `~/.config/coucou` | `dev.clove.notch`, `clove-notch`, `clove-notch-hook`, `clove-notch.sock`, `~/.config/clove-notch` |
| Character | Mochi (face, eyes, hands, outfits, greeting wave) | the CLOVE mark: four sepals and a bud in a state ring (`drawCloveMark` in `windows/src/mochi/engine.ts`) |
| Icon | Coucou icon | `windows/branding/clove-icon.svg` |
| Sounds | the Mac app's WAVs | `windows/branding/sounds`, generated by `windows/branding/make_sounds.py` |
| Wordmark | — | Eurostile Extended Bold if installed, else Michroma (SIL OFL, `windows/public/fonts`) |
| Wardrobe | outfits for Mochi | removed from the menu (the mark has none) |
| Updates | from upstream's GitHub releases | off: upstream releases are the original app |
| Accent of CLOVE's pill and chat | — | `#FB923C`, the CLOVE orange (the hub's accent); `clove/docs/DESIGN.md` lists the shared tokens |

Unchanged on purpose: links to the upstream repository (credit), and the phone-link protocol ids (`coucou://pair`,
`coucou-relay/v1`, `coucou.v1`, `_coucou._tcp`), so the phone app still pairs.

**Clove Notch** was called the CLOVE island until 0.2.0. Everything a person sees or types says Clove Notch: the app,
its settings, the commands `clove-notch` and `clove-notch-hook`, and its folders `~/.config/clove-notch` and
`~/.local/share/clove-notch`. On first start it moves the old `clove-island` folders and keys there and leaves a
link at each old path, so hooks written before the rename keep working. Names inside the code (`src/island/`,
`island.rs`, the window label `island`) are upstream's and stay, so upstream changes still merge.

## Connected to CLOVE

- **Chat**: the default chat provider is CLOVE (`windows/src-tauri/src/clove_chat.rs`). Questions go to the running
  CLOVE over its owner-only control socket (`~/.local/state/clove/ctl.sock`) and CLOVE answers with its own brain,
  memory and tools.
- **CLOVE's own pill**: CLOVE reports its requests, tool steps, replies and finished jobs to Clove Notch
  (`clove/notch.py`), and a plan that needs approval comes up as an Allow / Deny card that approves or rejects it.

- **The Assistant pages** (first in the window's sidebar, and its default page): the CLOVE assistant's own window
  (`clove/ui`) in a frame (`windows/src/hub/clove.ts`). Its address comes from `$XDG_RUNTIME_DIR/clove.url`, written
  by CLOVE at start and checked before use (`src-tauri/src/clove_window.rs`); the window's CSP allows frames from
  `http://127.0.0.1:*` only. When CLOVE isn't running the page says so and can start its systemd user service.
  `clove-notch --page assistant` opens the window there (CLOVE does this when it is asked for its window).

**Messages and calls, like a phone's notifications.** CLOVE sends a `CloveNotification` hook event (`kind`: message,
ringing, call, ended, replied; `sender`; `text`) for every message it sees (WhatsApp, Instagram, Telegram, X,
LinkedIn and the rest) and every call it rings, takes or ends. Each app gets its own pill in its own colour
(`agents.ts`, `app-*`), and the "message" view opens like a banner: the app, who, what, with Reply / OK, or
I'll take it / End call while CLOVE is on a call. The buttons tell CLOVE what to do as if he had said it
(`clove_tell`, over CLOVE's control socket). A pill goes a minute after its last message; a call's stays while the
call lasts.

## Live activities (this fork's own)

Clove Notch floats under the top edge as a pill and shows what is going on, as the Dynamic Island does: the most
important activity on both sides of the pill, and a card when it is opened (`src/core/live.ts`, `src/live/`,
`src-tauri/src/live/`). The cards are in English only for now.

- **One notch.** Every page has the same header (Home, Live, Controls, Time, Chat, Drop, the unread chips, CLOVE's
  mic, sound, Settings), the live cards included. Resting the pointer on the pill opens just that header, a bar of
  pages one click away; a click on the bar opens what a click on the pill would. A card that comes up by itself (a
  payment, a score) is shown alone, without the header, and folds back.
- **The circle beside the pill** carries the unread messages (the newest app's logo and a count) and opens the
  launcher: Ask CLOVE, timer, stopwatch, voice memo, navigate, stocks, scores, status, with the unread apps above.
- **A click on a card** keeps it open; a second click opens what it is about (the match, the quote, the order, the
  player). The wheel goes through the activities; the × on a match takes it off for good.
- **Controls** holds the to-dos and reminders (below) and the batteries of this computer and what is connected to
  it; **Time**'s calendar shows a picked day: its events, reminders and to-dos, and a reminder can be added for it.

### To-dos, reminders and the calendar

They belong to the CLOVE assistant (`assistant/agenda.py`, kept in its memory database), so the notch and the voice
change the same ones: "remind me tomorrow at 9 to call the bank", "move that reminder to 10", "add renew passport
by friday to my list", "what's on my calendar this week". The notch asks CLOVE over its control socket (`agenda
<json>`, `clove_agenda` in `src-tauri/src/clove_chat.rs`). Reminders are said and shown when due, also after a
restart. The calendar is read from its secret iCal address (Google Calendar: Settings → the calendar → "Secret
address in iCal format"), pasted under a picked day or given by voice; nothing is written to it.

| Activity | Where it comes from |
|---|---|
| Now playing (Spotify, YouTube, YouTube Music, Apple Music, mpv, VLC…) | every MPRIS player on the session bus |
| Microphone and camera dots, screen recording | PulseAudio/PipeWire streams, who holds `/dev/video*`, the recorder processes |
| Battery, earphones, mouse, phone | `/sys`, BlueZ, UPower, KDE Connect |
| Hotspot | NetworkManager (`nmcli`), clients from `iw` |
| Rides, orders, payments, calls, phone navigation | desktop notifications, read as a bus monitor (a phone's arrive through KDE Connect) |
| Fingerprint, password prompts, face unlock, unlock | fprintd, the journal (polkit, sudo, Howdy), the lock screen process |
| Timers, stopwatch, voice memos (`~/Music/Voice Memos`) | the notch itself |
| Stocks, scores, routes | CNBC's quote service, ESPN's scoreboard, Nominatim + OSRM (no keys) |
| The spoken conversation with CLOVE | the assistant (`assistant/notch.py`) |

Anything can be pushed from a script, one JSON line on `$XDG_RUNTIME_DIR/clove-notch.sock`:
`{"live": {"op": "timer", "duration": "5m", "label": "Tea"}}`. The ops are in `applyPush` (`src/live/control.ts`):
`timer`, `stopwatch`, `memo`, `navigate`, `stock`, `follow`, `voice`, `auth`, `payment`, `call`, `ride`, `delivery`,
`notification`, `media`, `dismiss`, `show`. The assistant's `notch` tool uses the same ops, so they work by voice.
`npm run dev` in a browser has them all with made-up data: `demo("ride")` in the console (`dev/live-demo.ts`).

## Build and install

```bash
npm install && npx tauri build --no-bundle
install -m755 target/release/clove-notch ~/.local/bin/clove-notch
install -m755 target/release/clove-notch-hook ~/.local/bin/clove-notch-hook
```
